# Возвраты за крутки в депозитах и выводах

Кнопка подарка открывает отдельный список розыгрышей. Вкладка «Крутки» показывает выдачи бонусов (`admin_debit`) и их результаты за выбранный в депозитах период (смена 06:00–06:00 МСК). Видны имя, Poker21 ID, назначение, дата/сумма выдачи, дата/сумма возврата; доступны поиск и фильтр менеджера.

Источник — существующий бонусный журнал `poker_app:bonus_ledger_all` / `poker_app:bonus_ledger:<id>` и результат проверки `poker_app:bonus_issue_reviews`. Поэтому отметки из раздела бонусов видны во вкладке, а сохранённые во вкладке — в бонусах. Второго денежного события не создаётся.

Форма «Указать возврат» фиксирует уже состоявшийся возврат фишек; автоматического снятия фишек или перевода денег не выполняет. Ноль означает «возврата нет». Повторное сохранение той же суммы ничего не удваивает; изменение требует актуальной версии исходной отметки и сохраняет историю. Суммы API депозитов в копейках, бонусный источник — в рублях.

В список попадает выдача за период либо более старая выдача с возвратом в этом периоде. В итоги возвратов входит дата подтверждения возврата, а не дата выдачи. Возврат относится к менеджеру, который записал его; депозиты и выводы не увеличиваются. Недоступность источника явно помечает итог возвратов неполным.

Новые действия существующего защищённого API `/api/admin-deposits`: `spin-returns` и `spin-return`. Действуют обычные проверка администратора и токен доступа к разделу. Для записи нужны `operationId`, `amount` (копейки) и `reviewVersion` из списка.

Проверки: `node --test tests/deposit-spin-returns.test.js tests/admin-deposits.test.js tests/deposit-raffle-prizes.test.js`; `node scripts/smoke-deposit-spins.cjs` (изолированный браузер, все API фиктивные).
