# Путь посетителя по ссылке

В CRM → Ссылки → Параметры каждая подтверждённая цепочка гостя/аккаунта показывается карточкой. Поля: переход, активность, регистрация, розыгрыш, крутка покера дня, Poker21, уровень героя, бот, Telegram-группа игроков и сумма подтверждённых депозитов CRM. История последних действий раскрывается внутри карточки.

Зелёное «Да» означает зафиксированный факт, красное «Нет» — отсутствие зафиксированного факта; неизвестные/непроверяемые статусы серые, не превращаются в «Нет». Регистрация до перехода помечается отдельно. Розыгрыши/крутки считаются после регистрации: для новых событий сохраняется признак серверно подтверждённого аккаунта; старые проверяются по дате регистрации, иначе результат неизвестен. Текущие подписки и уровень не выдаются за новые конверсии. Депозиты относятся к первому источнику привлечения; суммы до перехода и повторные записи исключаются существующей логикой attribution.

Источники: durable attribution events, подтверждённые account aliases, memberProfile, CRM deposits. Старые анонимные переходы без цепочки attribution невозможно честно связать с последующей регистрацией задним числом; старый журнал переходов остаётся доступен ниже.

## Telegram

Группа — закрытая ссылка с главной: https://t.me/+snBngKmXYa1mYjky, не @dva_tuza_club. Проверка членства — Telegram getChatMember; left/kicked дают «Нет», member/administrator/creator — «Да», restricted учитывает is_member. API error/нет идентификатора/нет прав — «Неизвестно».

ID группы берётся из TELEGRAM_PLAYERS_CHAT_ID или Redis poker_app:tracking:players_chat. Если ID ещё неизвестен, существующая группа уведомлений допускается только при совпадении getChat.invite_link с точной ссылкой на главной; иначе она не подставляется. Доверенный webhook chat_member/chat_join_request с этой invite_link может автоматически связать ID. Одна заявка на вступление не означает членство. Бот должен иметь доступ к проверке участников группы; при его отсутствии UI сохраняет неизвестный статус.

Статус бота фиксируется доверенными private my_chat_member и входящими личными сообщениями после проверки webhook-secret. Наследованные отметки подписок читаются как резерв. Клик на ссылку бота не является подпиской. Дополнительных сообщений пользователям или группам этот код не отправляет.

## Общие счётчики

«Переходы» — зарегистрированные открытия. «Посетители» — идентификаторы браузеров/устройств, не доказанное число людей. «С действиями» — пересечение зарегистрированных посетителей с подтверждёнными записями действий. «Действия» — сумма действий только этой группы. Исторический хеш unique и действия неизвестных посетителей больше не являются источником отображаемых итогов. Подсчёт не подгоняется min/clamp.

Переход и связанные счётчики записываются атомарным Redis Lua; события принимаются только для учтённого посетителя, обновление деталей также атомарно. Клиент ждёт завершения записи перехода и привязывает session cache к visitor ID вместо общего флага.
