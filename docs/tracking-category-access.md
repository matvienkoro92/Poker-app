# Персональный просмотр статистики категории

Во вкладке «Свои» в CRM выберите конкретную категорию, откройте «Доступ к категории», укажите получателя и создайте ссылку. Отдельная страница показывает только ссылки этой категории, общие показатели и матрицу игроков. Доступ к остальному приложению этим ключом не предоставляется.

Доступ действует у владельца ссылки, без авторизации в админке. Для разных получателей создавайте разные ссылки; каждую можно отозвать отдельно. Секрет показывается при создании; в Redis хранится только его SHA-256. Секрет находится во fragment URL, запросы отправляют его в Authorization. Ответы статистики не кешируются.

Категория проверяется сервером при каждом запросе, включая запрос отдельной статистики по ID. Автоматические ссылки CRM-рассылок всегда исключены, даже при совпадении категории. Новые свои ссылки категории появляются автоматически; перенесённые из неё становятся недоступны. Гостевой API не допускает изменений, произвольных таймлайнов или выдачи внутренних идентификаторов аккаунтов. Матрица передаёт только явно разрешённые поля.

Проверки: `node --test tests/tracking-category-access.test.cjs`.
