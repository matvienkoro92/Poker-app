# Кулершан

Безлимитная аркада: Кулер верхом на водяном кулере с вращающимся вентилятором пролетает между картами и стопками фишек ПокерМанки. Нажатие на игровое поле, пробел или стрелка вверх дают подъём. В каждом проходе можно собрать фишку: одна фишка даёт одно очко.

Вход: профиль → самый низ → «Кулершан». Прямая ссылка: `?startapp=cooler_flight`.

## Режимы

- Соло: личный рекорд на устройстве, серверный топ клуба, быстрый рестарт, пауза, отключаемый звук, экспорт PNG-карточки и системное меню отправки.
- Дуэль: авторизованный игрок создаёт комнату, отправляет код/ссылку другу. Второй участник запускает общий пятисекундный отсчёт. Одинаковый seed задаёт одинаковую трассу. Соперник показан полупрозрачной голограммой рядом с игроком на общем поле; стены рисуются перед голограммой. Его полёт не влияет на столкновения игрока.
- Сворачивание соло ставит игру на паузу. Сворачивание/выход из активной дуэли означает сдачу. Ссылка комнаты действует два часа; запущенная дуэль истекает через 12 минут. Повторный вход участника восстанавливает результат.
- Без авторизации/при недоступном сервере доступна тренировка. Она не публикуется в топ клуба.

## Данные и проверка

`app-cooler-flight-engine.js` — общая для браузера и сервера симуляция на фиксированных шагах 60 Гц. Сервер `/api/cooler-flight` выдаёт seed и привязанный к авторизованному аккаунту runId, воспроизводит последовательность нажатий, проверяет завершение и минимальную длительность. Присланное число очков игнорируется. Redis Lua атомарно завершает полёт и обновляет лучший результат, поэтому повторное сохранение и запоздалые live-обновления не меняют результат.

Redis: `poker_app:cooler_flight:v3:*`. Временные полёты/комнаты/положение — TTL 7200 секунд. `top` — sorted set, `names` — hash. Авторизация использует существующий `api-auth`, без новых секретов. При изменении правил симуляции нужны новая версия движка и новый Redis-префикс.

Серверный replay ограничивает простую подмену рекордов, но не является защитой от автоматического управления. Интерполяция соперника/низкая задержка через WebSocket в эту версию не входят.

## Арт

Спрайт создан встроенным image_gen по существующему Кулеру. Прозрачность сохранена. Итог: `assets/cooler-flight/cooler-pilot-v1.webp` (520×689, около 100 КиБ). Полный промпт и исходный путь: `assets/cooler-flight/prompt-v1.txt`. ПокерМанки и вращающийся вентилятор используют существующие изображения. Арт ежедневных турнирных сцен не изменялся.

## Проверки

- `node --test tests/cooler-flight.test.js`: 8 тестов физики, replay, авторизации, повторной отправки, дуэлей и сдачи.
- `npm run check:syntax`: проходит.
- `npm run build`: проходит.
- `SMOKE_ROOT=public node output/cooler-flight/check.cjs`: Chromium, управление, пауза, рекорд, экспорт карточки, топ, дуэль в двух браузерах с тестовым хранилищем, вход из авторизованного профиля, ширины 320/390/768, гостевая тренировка. Внешние API отключены. Скриншоты в `output/cooler-flight/`.
- Общий smoke-check: 12 прежних ошибок воспроизводятся на версии без добавленной игры. Сравнение: `output/cooler-flight/baseline-smoke.txt`, `current-smoke.txt`.

Проверка с настоящим Redis и авторизацией на опубликованном сервере выполняется после деплоя; локальный браузерный тест использует тестовое хранилище.

Локальная тренировка: `node output/cooler-flight/preview.cjs`, затем `http://127.0.0.1:4203/cooler-preview`.

Версия 3: рекорд — число собранных фишек (+1 за фишку в проходе), сложность растёт ступенями каждые 5 пройденных ворот, стартовая скорость 2.1 и проход 260. Стеновые выступы включены в столкновения. Визуальный размер героя — 122, круг вокруг героя скрыт. Голограмма соперника воспроизводит его нажатия с буферизацией. Старые рекорды отделены новым пространством v3.

Реванш сохраняет комнату и участников. После завершения обоих полётов участники нажимают «Повторить»; сервер атомарно создаёт новые runId, seed и общий отсчёт только при готовности обоих. Повторные запросы привязаны к предыдущему runId. Завершивший раньше автоматически наблюдает полный полёт соперника с буферизованным воспроизведением нажатий.

Одиночная игра (включая тренировку) начинается после отсчёта 3–2–1. Меню результата закрывается крестиком; касание поля снова открывает его. Закрытие сохраняется при обновлениях результата дуэли.

Версия движка 4: импульс нажатия -4.75 вместо -4.6 (примерно +3% по времени подъёма). Изображения стен, карт и стопок фишек кешируются для каждого препятствия; подсказка в DOM обновляется только при изменении.

Версия 5: стартовая скорость 2.35 (прежний второй этап), перепады ворот 48–90 с чередованием подъёмов и спусков; на поздних этапах перепады ограничены 75 для достижимости. Импульс -4.8, ускорение падения 0.235, предел падения 6.6. Проверка производительности: `FLIGHT_PERF=1 SMOKE_ROOT=public node output/cooler-flight/check.cjs` замедляет CPU в Chromium в 4 раза и измеряет длительность игровых кадров.

Отрисовка интерполирует положение героя и препятствий между фиксированными шагами, в том числе на экранах 120 Гц. Кеш учитывает плотность экрана и освобождается при выходе из игры; браузерная проверка подтверждает остановку отрисовки после перехода в другой раздел.
