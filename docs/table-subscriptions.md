# Подписки на активные столы

В клубном боте кнопка «🔔 Подписаться» открывает два сценария:

- Игра: Холдем, PLO4/5/6, Дурак, 21, OFC, Сека. Лимит — любой,
  точный `5/10` или «от `25/50`» (сравнивается большой блайнд).
- Игрок: поиск по нику из последнего отчёта или ввод Poker21 ID.
  Выбранный ID сохраняется независимо от ника.

Подписки относятся к публичному союзу Анти-Рег (`leagueId: 184691`).
В группе кнопка даёт ссылку на личку текущего бота; пользователь нажимает
Start и включает подписку самостоятельно. `/подписки`, `/subscriptions`
и `/start tablesub` открывают личное меню. «Мои подписки» позволяет удалить
каждую подписку. Максимум 20 подписок на пользователя.

При включении записывается текущая рассадка. Сообщения отправляются при
переходе стола в активное состояние или появлении игрока за новым столом.
Повторная посадка после наблюдаемого ухода также вызывает уведомление.
При неизменной рассадке подписки не перезаписываются в Redis; порядок строк
в ответе API не считается изменением.
При ошибке API предыдущая рассадка сохраняется. Уведомления используют
проверку прав пользователя, блокировку и маркеры доставки, чтобы параллельные
запуски не дублировали сообщения. Заблокировавшие бота пользователи исключаются.

Подписки включены только в клубном боте «Два туза». В боте Poker21
кнопки, обработчик подписок и endpoint доставки удалены. Его обычный
вывод столов и ников сохранён.

Процесс работает в проекте клубного мини-приложения и запускается Vercel
каждые 5 минут через `/api/cron-table-subscriptions`. Рассадка запрашивается
один раз. При отсутствии изменений и незавершённой очереди подписки
пользователей не читаются.

При сохранении и удалении подписки обновляются индексы Redis: ID игрока,
игра с любым лимитом, игра с точным лимитом, игра с минимальным большим
блайндом. Для минимального лимита используется sorted set. Новая посадка
выбирает только подписчиков этого игрока. Активация стола или смена его
игры/лимита выбирает подходящих подписчиков игры. При уходе или закрытии
обновляется состояние заинтересованных подписок, чтобы следующая посадка
или повторная активация вновь вызвали уведомление. Полный перебор всех
пользователей в рабочем cron не выполняется.

Требуются Redis, токен клубного бота и `CRON_SECRET` в Production.
Дополнительный секрет связи с Poker21 больше не нужен. Endpoint защищён
от запросов без действующего секрета. За запуск отправляется до 30
сообщений; незавершённая очередь и интересы сохраняются для повторной
проверки, даже если рассадка не меняется. Маркеры доставки хранятся 24 часа,
а после наблюдаемого ухода со стола удаляются.

Изменения, полностью произошедшие между проверками, API не позволяет увидеть.
Текущий API не возвращает рассадку всех турнирных столов; уведомления о посадке
для таких столов возможны только после появления `pos` в ответе поставщика.

Проверка: `node --test tests/table-subscriptions.test.js`.
