# Реакции в нардах и бильярде

Кнопка «Реакции» доступна во время игры с компьютером, тренировки и онлайн-партии.
Зритель видит реакции, но не отправляет их. В шахматах и дартсе кнопки нет.

Первая реакция — `pumpkin-haha`: присланный владельцем ролик длиной 4,23 секунды,
перекодированный из Photo JPEG / PCM MOV в MP4 с видео и звуком.
Файл: `assets/game-reactions/pumpkin-haha.mp4`. Исходный файл остаётся неизменным.
Плоская серая подложка убирается при рисовании видео на прозрачном canvas.

`scripts/shared/game-reactions.mjs` добавляет панель, воспроизведение и подавление
повторных событий. Видео не перехватывает нажатия по полю. Громкость общая с
игрой; если браузер запрещает автоматический звук, видео запускается без звука
с кнопкой его включения. После закрытия игры или ухода в фон воспроизведение
останавливается.

Для онлайна `action: reaction` использует `lib/game-reactions.js`:
- проверяет, что отправитель — участник начавшейся незавершённой партии;
- разрешает только заранее известные идентификаторы роликов;
- атомарно ограничивает частоту до одной реакции игрока за 6 секунд;
- хранит короткоживущие события отдельно от позиции, ревизии и расчётов ставок;
- отдаёт реакции при обычном опросе `room` / `watch`.

Новые сценарии отправки в Telegram не добавлены. Реакции видны только внутри игры.
Проверки: `node --test tests/game-reactions.test.cjs` и
`node tests/game-reactions-browser.cjs` (реальное воспроизведение MP4).

Панель выбора показывает сетку из трёх миниатюр в ряд. Каждый WebP — первый кадр
соответствующего видео с удалённой подложкой и кадрированием по персонажу.
Нажатие на миниатюру запускает видео, подпись и доступное имя сохраняются.
