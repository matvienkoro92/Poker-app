## Follow-up: быстрая загрузка вкладки Рейкбек - 2026-05-19

Этот follow-up фиксирует рабочее состояние после жалобы на долгую загрузку вкладки `Рейкбек` и раскрытия `Пустые записи недели` примерно по 16 секунд. Текущее поведение подтверждено пользователем как быстрое и комфортное.

- Вкладка `Рейкбек` открывается через единый быстрый shell `pokerOpenAdminReportRakebackShell`. Полный `app-admin-reports.js`, если загрузился позже, использует уже созданный `window.__adminReportRakebackShellModule` и не навешивает второй активный контур обработки таблицы.
- Старые обработчики рейкбека в полном модуле должны сразу выходить, если shell-модуль уже активен. Это защищает от двойных кликов/двойной отрисовки и возврата статуса `Загружаю рейкбек...`.
- Файл шаблонов `app-admin-reports-rakeback-data.js` прогревается тихо после входа во вкладку, но скрытые шаблонные строки не рисуются, пока пользователь не раскроет `Пустые записи недели`.
- При раскрытии шаблонов строки добавляются батчами через `requestAnimationFrame`; текущий батч увеличен, потому что сам список небольшой и должен появляться почти сразу.
- Smoke теперь разрешает безопасный прогрев данных шаблонов в закрытом состоянии, но запрещает отрисовку скрытых шаблонных строк до раскрытия.

### Рейкбек-таблица

- Румы вынесены из колонки в четыре подвкладки: `Покер21`, `Хпокер`, `Супрема`, `PPpoker`.
- Колонка `Рум` скрыта из строк, потому что активный рум теперь задается подвкладкой.

- У подзаписи рядом с `Рейк` показывается `Остаток`, который считается как текущий `Рейк` минус предыдущий `Рейк` в той же группе.
- У подзаписей `Рейкбек` считается от `Остатка * Процент / 100`, а не от полного рейка.
- К подзаписям также добавлена кнопка `+`, чтобы можно было продолжать цепочку.
- Подзапись можно добавить только к заполненной и сохраненной строке с ненулевым `Рейк`.

### Кнопки строк

- Зеленая галочка означает сохранение строки и видна только в момент ввода заполненной несохраненной строки.
- После сохранения галочка заменяется на кнопку-карандаш для редактирования.
- В пустой строке карандаш не показывается.
- Крестик сразу красный и запрашивает подтверждение удаления.
- Удаление сохраняется на сервер сразу и не должно возвращать строку после автообновления.
- Добавлена защита от гонки: если пользователь удалил/изменил строку после старта загрузки, старый ответ загрузки не перерисовывает таблицу обратно.

### Общая таблица и владельцы строк

- Рейкбек-таблица стала общей для админов и сохраняется через серверный ключ `poker_app:admin_report_rakeback_draft:shared`.
- Старые локальные черновики поднимаются в общий ключ, если серверный черновик пустой.
- Сервер хранит `ownerId` строки и при сохранении сливает данные по менеджерам, чтобы один менеджер не перетирал строки другого.
- Вкладка `Рейкбек` остается общей для просмотра, но поле `Рейкбек` на вкладке `Отчет` считает только строки текущего менеджера.
- В отправляемый отчет попадают только `rakebackRows` текущего менеджера:
  - введенное Викой попадает в отчет Вики;
  - введенное Аней попадает в отчет Ани;
  - введенное Романом попадает в отчет Романа.
- Автообновление общей таблицы идет только когда открыта вкладка `Рейкбек` и пользователь не печатает прямо в таблице.

- Общая таблица не означает общий отчет: просмотр общий, итог отчета персональный.
