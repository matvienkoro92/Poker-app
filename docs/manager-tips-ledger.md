# Чаевые менеджеров

В разделе ☕ две операции:

- **Получены чаевые**: рум, ID игрока, сумма, необязательная связь с банковским выводом. Это уже состоявшийся вывод фишек игрока в пользу текущего менеджера. Связанная заявка содержит только сумму игроку, без чаевых.
- **Обналичены чаевые**: выбранный остаток менеджера/рума, рум и ID игрока, получающего фишки, сумма. После получения денег менеджером это депозит игрока. Остаток чаевых уменьшается. Банковские заявки и деньги кассы клуба этой операцией не изменяются.

Все суммы сохраняются в копейках; стоимость учёта — 1 фишка = 1 ₽. Рум исходных чаевых и рум пополняемого игрока сохраняются отдельно.

Пример: получено 1 000 ₽ от игрока A → вывод A 1 000 ₽. Обналичено 600 ₽ через игрока B → депозит B 600 ₽, остаток менеджера 400 ₽.

Остаток считается за всё время отдельно по менеджеру и исходному руму. Фильтр отчёта ограничивает операции периода, но не обнуляет остаток с началом нового дня. Старые записи чаевых остаются полученными чаевыми; исторические обналичивания автоматически не предполагаются.

Обналичивание распределяется по конкретным поступлениям FIFO (`tipAllocations`). Нельзя потратить больше остатка. Менеджер может списывать только свои чаевые; владелец может выбрать менеджера. Отмена обналичивания возвращает фишки в остаток и убирает депозит из учёта. Получение нельзя отменить, пока существует связанное действующее обналичивание. Все отменённые записи сохраняются.

Отчёт учитывает получение как вывод игрока, обналичивание как депозит. Обналичивание выделено отдельным направлением «Обналичены чаевые», чтобы не попасть повторно в «На выводы» или в платёжные каналы. Атрибуция депозитов также учитывает обналичивания. Новых Telegram-рассылок нет.

Проверки: 120 unit/API/notification/attribution tests; мобильный сценарий на 320/390 px, включая потерю ответа, безопасный повтор и отмены. Параллельные списания защищены существующим CAS общего журнала.
