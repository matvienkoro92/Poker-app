# Ежедневное обновление рейтинга

## Быстрый ежедневный режим

Сложить скриншоты в одну папку и выполнить:

```bash
npm run rating:daily -- /путь/к/папке
```

Команда сама запускает OCR, нормализует игроков по Poker21 ID, исключает красные
результаты и повторные изображения, сжимает файлы, импортирует данные, обновляет
дату, пересчитывает рейтинг и собирает `public/`.

Перед проверкой без записи:

```bash
npm run rating:daily -- --dry-run /путь/к/папке
```

Если встретился новый Poker21 ID, автоматический импорт остановится и покажет
только неизвестную строку. Нужно один раз добавить пару `ID: "правильный ник"` в
`rating-player-id-map.json`, после чего этот игрок всегда будет исправляться
автоматически.

SHA-256 обработанных исходников хранится в `rating-import-history.json`.
Повторный файл пропускается, даже если его переименовали.

## Ручной OCR-режим

```bash
npm run rating:ocr -- /путь/к/IMG_0001.PNG /путь/к/IMG_0002.PNG
```

OCR автоматически определяет дату, время, название, бай-ин и лигу, отбрасывает
отрицательные результаты и распознаёт места 1–3 по цвету золотого, серебряного
или бронзового кубка. Перед импортом остаётся быстро сверить сложные ники с
кириллицей, эмодзи или декоративными символами.

## 2. Проверить импорт без записи

Сохранить исправленный черновик в текстовый файл и выполнить:

```bash
npm run rating:import:summer -- --dry-run < rating-day.txt
```

Сводка должна показать ожидаемое число турниров, положительных результатов и
очков в обеих лигах.

## 3. Записать обновление

```bash
npm run rating:import:summer < rating-day.txt
```

Импортёр:

- выбирает июньский, июльский или августовский файл по дате;
- заменяет повторно импортируемый турнир, не создавая дубль;
- сжимает исходные скрины в JPEG до 30 КБ;
- добавляет изображения в карту соответствующей лиги;
- обновляет подписи с датой;
- проверяет данные и синтаксис;
- пересчитывает итоговый рейтинг и собирает `public/`.

Формат одного турнира:

```text
date: 13.07.2026
league: 2
time: 22:00
name: EnergetikTournament
buyin: 200
source: /Users/name/Downloads/IMG_0001.PNG
players:
2 | MilkyWay77 | 4630
3 | мистерFox | 1890
```
