# Исправления технического аудита, 11 сентября 2026

## Изменения

- Приватный кеш: атомарное сравнение состава и состояния события перед бронированием, в том числе при ручном добавлении и подтверждении администратором. Одновременные конфликтующие запросы получают 409; повтор после обновления списка безопасен. Исправлено выделение мест резерва при наличии пропусков. Отмена, отклонение и предупреждения защищены от перезаписи устаревшим состоянием.
- Переводы: серверная проверка блокировки аккаунта; сохранение переходов статуса через compare-and-set. Подтверждение одной сделки учитывается ровно один раз; повторный конкурентный запрос получает 409. Проверки типов счётчиков выполняются до записи.
- Стена: при ошибке чтения/записи возвращается 503; при конфликте — 409. Успешный конкурентный пост не затирается, уведомление не отправляется до подтверждённого сохранения.
- Вложения чата: сервер выдаёт временную подпись только внутри уже авторизованного ответа чата, привязанную к читателю и конкретному файлу. Прокси проверяет подпись и блокировку аккаунта. Фото, голосовые и PDF используют прокси в Telegram и PWA; ответы не кешируются общим кешем.
- PWA: новая версия ожидает активации; открытый экран не перезагружается автоматически. Пользователь применяет обновление кнопкой. Кеш новой версии — `poker-static-v58`.
- SNG: каталог изображений синхронизирован с рейтингом, fallback-баннер приведён к текущему. Устаревшие тестовые ожидания и daily-poker фикстуры обновлены.
- Стартовая загрузка: 30,7 KB исходных стилей героя перенесены в отдельный файл, загружаемый с профилем/чатом. CSS для разбора на старте уменьшился с 888,7 до 860,1 KiB. Бюджет 760 KiB ещё превышен; полной оптимизации начальной загрузки это изменение не заменяет.

## Хранение вложений и выпуск

Публичные фотографии стены остаются публичными и используют префикс `wall/`. Это отдельная политика от приватных диалогов.

Для новых вложений чата можно подключить **отдельный private Blob store** и передать `CHAT_BLOB_READ_WRITE_TOKEN`. Старый `BLOB_READ_WRITE_TOKEN` остаётся для публичных файлов. Не следует передавать токен публичного store как private-токен. Без private-токена новые вложения сохраняются inline внутри защищённых сообщений Redis, как в существующем локальном режиме. Это безопасный вариант по умолчанию, но для объёмного чата предпочтителен private store.

Подписи используют `CHAT_MEDIA_SIGNING_SECRET`, если он задан; иначе имеющийся серверный Blob-токен. Смена ключа инвалидирует старые ссылки; повторное открытие сообщений выдаёт новые. Срок ссылки — один час.

**Обновление кода само по себе не делает уже опубликованные файлы приватными.** Для них добавлена миграция:

```sh
node scripts/migrate-chat-media.js
node scripts/migrate-chat-media.js --apply
```

По умолчанию выполняется только подсчёт. Миграция сканирует ссылки в сохранённых сообщениях общего, личных и групповых чатов. При применении она сохраняет проверенную private-копию (или inline-копию в Redis при отсутствии private store), записывает постоянное соответствие старой ссылки новой, проверяет запись и только затем удаляет публичный оригинал. Прокси читает это соответствие, поэтому историю сообщений переписывать не требуется. При ошибке сохранения оригинал не удаляется. Повторный запуск использует существующие соответствия. Таблицу `poker_app:chat_media_migration:*` удалять нельзя — на неё опирается история.

Порядок выпуска: развернуть сервер и клиент с этими изменениями, выполнить dry-run с рабочими credentials, затем миграцию. В текущей рабочей среде credentials Redis/Blob отсутствуют: производственная миграция и деплой не выполнялись. Удалённые ранее сообщения, файлы без ссылок в оставшейся истории и внешние копии вложений этой миграцией не охватываются.
