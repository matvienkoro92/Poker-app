Фильтр по умолчанию показывает текущую неделю; для этой выгрузки выбрать 7–13 сентября.

## Подготовка

`scripts/prepare-club-hands.py` создаёт отдельную проекцию и повтор для каждого владельца. Поддерживаются NLH и отдельные разновидности Omaha: PLO4, PLO5 и PLO6. Сырые карты других игроков не попадают в события; показанные на вскрытии карты отбирает существующий `visible_opponent_cards`. Старый результат импорта NLH: 60 654 уникальные раздачи, 139 072 участия для 211 игроков (42 110 кеш, 91 670 MTT, 5 292 SNG). Новые импорты сохраняют вид игры в каждой записи и не смешивают Omaha с холдемной матрицей стартовых рук. Неизвестные игровые коды и раздачи с неоднозначным большим блайндом исключаются.

`scripts/upload-club-hands.cjs` без `--apply` читает текущие версии и создаёт локальный план. В существующих раздачах сверяются владелец, карты, время, формат, единицы, результат и блайнд; расхождение останавливает подготовку. Старые записи, EV и повторы сохраняются. Новых участий 136 408, уже загруженных — 2 664.

С `--apply` скрипт записывает отдельную версию каждого профиля, проверяет число полей и точное содержимое всех новых полей, затем атомарно переключает указатель при неизменной исходной версии. Предыдущие версии сохраняются. Повторный запуск того же плана пропускает уже активированные версии. Журнал в `output/club-hand-import/upload-journal.jsonl` содержит старый/новый указатели и проверенные счётчики. Локальные файлы в `output/club-hand-import` содержат личные данные и не предназначены для публичной сборки.

## Проверки

- 17 тестов API и статистики: доступ только по серверной привязке, расчёты.
- 19 Python-тестов парсера позиций и вскрытия.
- 4 теста пакетного импорта: сохранение EV и истории, идемпотентность, отказ при конфликте и чужом владельце.
- Все 139 072 подготовленные записи приняты модулем `lib/hand-statistics.js` с совпадающими счётчиками по игрокам и форматам.

Код интерфейса и API не меняется; для появления данных не требуется новая публикация приложения. Денежные единицы кеша остаются единицами стола; турнирные результаты — фишками.

Форматы разнесены по исходному DeskType: 2 — cash, 3 — SNG, 4 — MTT; неизвестный код исключается. Отдельное уточнение SNG сохраняет повтор, EV и все суммы, меняя только категорию.
