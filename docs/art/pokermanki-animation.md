# PokerManki head animation

Built-in image_gen precise edit: preserve original full pose and composition; change only eyes to naturally closed for a blink. Only an eyelid crop from the result is used, so its generated backdrop is excluded.
Head layer is cropped from the approved transparent v3 image. Native SVG mask removes the original static head; CSS moves the head around its neck and reveals a feathered eyelid patch twice per 6.4 seconds. Reduced motion retains the original static portrait.
Assets: assets/pokermanki-animation-head.webp, assets/pokermanki-animation-eyelids.webp, assets/pokermanki-animation-body-mask.svg.
