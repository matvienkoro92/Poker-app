# Личный зал игрока

В профиле на вкладке достижений находится вход «Мой зал». В карточке другого игрока — «Зал игрока». Общий клубный Зал славы остаётся самостоятельным разделом.

Личный кабинет использует новый фон `assets/player-hall/cabinet-study-v3.webp`, созданный встроенным imagegen: настоящий ореховый шкаф со стеклом, тремя полками и общей тёплой подсветкой. Пять выбранных предметов стоят на физических полках: первый — главный, ещё четыре — на двух нижних. На табличках — название турнира/награды и дата/итог лиги. Персонаж и большие кнопки убраны из комнаты; навигация по разделам находится под витриной.

Четыре согласованных прозрачных предмета: `award-cup-v3.webp` для победы, `award-medal-v3.webp` для призового места/положительного результата, `award-plaque-v3.webp` для сезона или клубного достижения, `award-memory-v3.webp` для совместного воспоминания. Рамка содержит тематическую иллюстрацию покера, не фотографию конкретного события. Произвольных подписей вроде «Король МТТ» на трофеях нет. Нажатие приближает выбранный предмет из его позиции до окна подробностей; при reduced-motion приближение отключено.

Коллекция открывается отдельным экраном с фильтрами. Витрина и порядок сохраняются по прежней схеме без миграции. Три варианта подсветки: тёплый свет доступен сразу, зелёный после первой победы, вечерний после пяти. Следующую цель можно выбрать по победам или наградам «Герой дня». Промпты и пути итоговых артов: [player-hall-v3-art.md](player-hall-v3-art.md).

`POST /api/player-hall`, action `get` (необязательный targetId) или `save`. Сервер разрешает редактировать только зал авторизованного аккаунта. Сохранение принимает version, featured (до пяти уникальных серверных ID), theme и goal. CAS защищает от перезаписи параллельных изменений. Данные хранятся в `poker_app:player_hall:<accountId>`, независимо от оформления профиля и пилотной системы героя. Чужой зал доступен только для просмотра.

Достижения связаны с проверенным ником Poker21. Турнирные воспоминания строятся из `friend-tournament-results.json`; выдача опирается только на опубликованные положительные результаты. Сохранение зала фиксирует серверные памятные предметы, поэтому они остаются после обновления текущей ленты. При смене привязанного ника старые предметы другого игрока не выдаются. Награды за все участия и финальные столы не вычисляются по неполным данным.

Завершённые сезоны генерируются скриптом `scripts/generate-player-hall-seasons.js` через общие функции расчёта рейтинга профиля. Лето включает июнь–август. Сентябрь и октябрь не входят в итог лета. Генератор включён в build/build:static; JSON остаётся серверным источником. При добавлении нового завершённого сезона расширить генератор.

Проверки: `node --test tests/player-hall.test.js tests/club-social.test.js tests/hero-memories.test.js`, `node scripts/test-player-hall-browser.js`, `npm run check:syntax`, `npm run build`. Браузерная проверка использует локальные файлы и тестовый API без записей в реальные аккаунты. Проверяет 320/390/768 px, увеличение, полки, ограничение витрины, порядок, повтор сохранения после ошибки сети, открытие сохранённого зала, просмотр друга, выход из аккаунта и пустую коллекцию. Скриншоты — `output/player-hall/`.

Проверка изображений: браузерный тест ждёт `img.decode()` для комнаты, коллекции и подробностей, поэтому сломанные картинки завершают тест ошибкой. `SMOKE_ROOT=public HALL_LIVE_ORIGIN=https://poker-app-ebon.vercel.app node scripts/test-player-hall-browser.js` проверяет изображения с сервера, подменяя API зала тестовыми данными. Адреса всех кубков перечислены полностью и версионированы; при ошибке загрузки выполняется одна повторная попытка, затем показывается резервный символ награды вместо сломанного изображения.

## Комната на весь экран (7 октября 2026)

Вкладка «Комната» занимает весь мобильный экран. Обезьяна в зелёном костюме сидит в кожаном кресле; шкаф и полки являются частями одной сцены. Нажатие на мебель перемещает и приближает камеру; кнопка возврата восстанавливает общий план. Нажатие на награду открывает её историю. Коллекция и настройки доступны через нижнюю навигацию. При reduced-motion смена плана происходит без анимации. Пять сохранённых наград и серверная модель остаются совместимыми.
