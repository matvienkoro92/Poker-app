# Проверка перед работой над CSS — 11 сентября 2026

Проверена версия a4c41208 и исправление отмены загрузки разделов. Проверка не означает, что все возможные действия и сочетания устройств покрыты.

## Найдено и исправлено

При быстром переходе с загружаемой главной обратно в уже открытый чат заставка главной могла оставаться поверх экрана и блокировать кнопки. Отменённая навигация теперь сразу убирает свою заставку; таймер завершения предыдущей загрузки не может скрыть новую заставку. Добавлены три регрессионных теста и браузерный сценарий сохранения черновика, двойного клика и повторной отправки после HTTP 503. Кэш PWA обновлён с v60 до v61.

## Результаты автоматических прогонов

- 264 существующих unit-теста — успешно; 3 новых теста отмены загрузки — успешно.
- 75 контрактных сценариев — успешно.
- Расширенные проверки целостности с настоящим изолированным Redis — успешно.
- Навигационный smoke с глубокими административными сценариями — успешно на финальной сборке.
- Базовый chat smoke — успешно; отдельный recovery smoke на финальной сборке — успешно.
- Математика клавиатурного дока: 8 сценариев — успешно.
- Визуальный smoke: 11 представлений — успешно.
- Browser smoke: загрузка, административный рейкбек и PokerPlus — успешно.
- CRM: актуализированный локальный сценарий превью и тестовой отправки — успешно. Массовая рассылка этим дополнительным сценарием не проверялась.
- PWA update — успешно.

Исходный дополнительный CRM smoke ожидал удалённые элементы интерфейса (список сегментов, старую кнопку отправки) и не включал переключатель кнопки ссылки. Его падения не подтверждали дефект приложения. В одном навигационном прогоне проверка общего счётчика запросов пересеклась с фоновым сохранением: запрет удаления средней подзаписи сработал, строки не изменились; отдельный повтор всего сценария прошёл. Это место теста чувствительно ко времени выполнения.

## Что осталось

Для завершения живой приёмки нужно разблокировать CRM, отчёты и административные балансы, затем проверить их рабочие экраны. Пароль не извлекался и защита не обходилась. Реальные сообщения, рассылки, выплаты и балансы в ходе проверки не менялись. Загрузка старой истории чата не подтверждена: нативное окно стало недоступно во время проверки; данных, доказывающих падение самого приложения, нет.

Работу над CSS можно начинать. Утверждать, что приложение полностью проверено и больше не содержит ошибок, оснований нет; закрытые рабочие экраны и реальные мобильные устройства остаются отдельной приёмкой.
