# Архив рейтингов в Blob

Скриншоты января–мая 2026 и их миниатюры публикуются в подключённый публичный Vercel Blob. Очки, места и остальные данные рейтинга не меняются. Адреса изображений доступны без авторизации.

`scripts/publish-season-archive.js` берёт архивные изображения из `public/assets`, создаёт отдельный префикс по хешу содержимого, загружает файлы без перезаписи существующих объектов и проверяет каждый публичным GET и SHA-256. Только после проверки всех файлов записывается `season-archive.json`. Запись прогресса в `output/asset-audit` позволяет продолжить прерванную загрузку.

Сборка читает адрес из `season-archive.json`. Изображения, используемые прямыми URL в газете, сохраняются локально; остальные архивные изображения исключаются только после проверки хеша исходника по манифесту. Новый или изменённый архивный скриншот требует повторной публикации архива.

## Публикация обновлённого архива

1. Собрать полную локальную версию: `POKER_ARCHIVE_ASSET_BASE_URL='' npm run build`.
2. Проверить список: `node scripts/publish-season-archive.js`.
3. С доступным в окружении `BLOB_READ_WRITE_TOKEN` выполнить `node scripts/publish-season-archive.js --apply`.
4. Выполнить `npm run build:static` и `node --test tests/season-archive-build.test.js`.
5. Деплой приложения выполняется отдельно. В коммит включаются манифест, скрипты и тесты, но не секреты или файлы прогресса.

## Возврат к локальным файлам

Собрать с явным пустым `POKER_ARCHIVE_ASSET_BASE_URL=''`. Это переопределяет сохранённый адрес и возвращает архивные файлы в сборку. Исходники в `assets` сохраняются. Для постоянного отключения удалить `season-archive.json` и убедиться, что переменная адреса не задана в окружении деплоя.

## Проверки

`node --test tests/season-archive-build.test.js` проверяет исключение архива, сохранение прямых ссылок газеты и текущего сезона, отказ при неверных хешах и маршрутизацию миниатюр. Сбой Blob влияет на открытие старых изображений, а не на таблицы рейтинга. Хранение и трафик учитываются тарифом Blob.
