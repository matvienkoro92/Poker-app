Arms swing opposite legs. Important visibly DIFFERENT opposite-leg phases; not six identical poses. Full body including BOTH COMPLETE SHOES and tail in EVERY cell, no clipping. Consistent head size body proportions same character identity, constant camera true profile, clean polished 3D videogame sprite art.
