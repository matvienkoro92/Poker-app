# Дартс

Дартс остаётся закрытым для обычных игроков. Вход в интерфейс требует
`adminGameAccess`, а API отклоняет создание, вход и просмотр комнат дартса
для пользователей без административного доступа. Снятие ограничения — отдельное
решение владельца.

## Меню и игра

Пошаговое меню: режим → вход 0 / ставка (для друга и вызова) → формат.
Доступны компьютер, тренировка обеих сторон, комната по ссылке, вход по коду,
поиск соперника и вызов в чат игроков. Партия состоит из 3, 5 или 10 раундов,
по три дротика за подход. Побеждает сумма очков. Серия — до трёх побед;
ничья не добавляет победу. Слабый/сильный свайп смещает попадание по вертикали,
боковое движение и отклонение траектории — по горизонтали. Клавиатурный бросок
использует удержание и отпускание кнопки на шкале силы.

`app-villa-darts.js` содержит интерфейс и чистые функции подсчёта попадания.
`app-villa-darts-menu.js` отвечает за мастер настройки,
`app-villa-darts-online.js` — за запросы, опрос комнаты и восстановление
незавершённого создания. При сборке `copy-to-public.js` объединяет зависимости
дартса в один файл и явно выставляет `globalThis.PokerDarts`, поскольку приложение
загружает файл через динамический импорт.

## Онлайн

Используется существующий `/api/board-games` с дисциплиной `darts`.
`scripts/board-games/darts.mjs` рассчитывает попадания на сервере, проверяет
очередь, допустимые параметры и число бросков. Клиент не задаёт начисленные очки.
Время даётся на весь подход; отдельный дротик не продлевает его. Три собственных
пропуска времени подряд означают поражение.

Комнаты, сравнение ревизий, ставки Poker21, возвраты, выплаты, предложения
повторного матча, рейтинг и личные встречи используют общую инфраструктуру нард.
Для подбора соперника учитываются время, формат серии и число раундов.
Вход на фишки требует подтверждения условий. Сдача платного матча завершает
всю серию; комиссия — 5% общего банка. При ничьей ставки возвращаются.
Неопределённое создание восстанавливается по прежнему идентификатору запроса.

Мишень и дротики сохраняются в аккаунте отдельным обновлением `dartsOnly`,
которое сохраняет оформление шахмат и нард. Комната получает проверенный сервером
снимок оформления создателя. Он общий для обоих игроков и зрителей. Гость не может
сохранить оформление комнаты как своё; после выхода восстанавливается личное.

Приглашения: `darts_<код>` и `darts_watch_<код>` в Telegram startapp.
Вызов в чат и результат используют уже существующие разрешённые сценарии
`board-games-challenge`, `board-games-challenge-accepted` и `game-result`.
Новые команды или автоматические ответы Telegram не добавляются.

## Проверка

- `node --test tests/darts-online.test.mjs tests/villa-darts.test.js`
- `node --test tests/board-games-room.test.cjs tests/board-games-stats.test.cjs tests/board-games-access.test.cjs tests/board-games-wagers.test.js`
- `node tests/villa-darts-browser.cjs`
- `node tests/darts-online-browser.cjs`

Браузерные проверки используют локальные ответы API и тестовые балансы:
настоящие списания и сообщения не выполняются. Онлайн-проверка загружает
собранный файл через динамический импорт и проверяет двух игроков и зрителя.
