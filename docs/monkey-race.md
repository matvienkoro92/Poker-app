# На последнюю регистрацию

ПокерМанки едет на моторном кресле по трём дорожкам. Свайпы вверх/вниз меняют дорожку, нажатие/пробел — прыжок. Высокие металлические барьеры объезжаются, низкие можно перепрыгнуть. Собранная фишка даёт 5 очков и каждую третью — заряд ускорения на 1,5 секунды. Скорость растёт каждые 6 препятствий с пределом. У каждого участка есть свободные дорожки.

Одиночный заезд идёт до столкновения (технический предел 10 минут); дуэль — до столкновения или 60 секунд. Очки складываются из дистанции и собранных фишек. В дуэли одна трасса/время старта, соперник отображается полупрозрачно с ником. Повторный заезд в той же комнате запускается после готовности обоих. При сворачивании одиночная игра ставится на паузу, дуэль завершается выходом. У этой игры нет билетного призового круга Кулершана.

Детерминированная физика — `app-monkey-race-engine.js`; сервер воспроизводит ввод и подтверждает результат. Ввод кодируется `tick * 5 + action` (1/2 дорожка, 3 прыжок, 4 ускорение), минимум 7 тактов между командами. Отдельное хранилище Redis `poker_app:monkey_race:v1:`. API `/api/monkey-race`, просмотр рейтинга публичный, сохранение и дуэли требуют аккаунта. Без сервера доступна тренировка без сохранения. Арт `assets/monkey-race/pokermanki-chair-v1.webp`.

Проверки: `node --test tests/monkey-race.test.js`; мобильный UI/две сессии/реванш/выход: `SMOKE_ROOT=public node output/monkey-race/check.cjs`.

Графика: индустриальный тоннель в ретро-стиле, движущийся пол и параллакс стен, светящиеся разделители дорожек. Фон и препятствия рисуются один раз в небольшие canvas-текстуры; во время игры используются drawImage. Проверка с замедлением CPU в 4 раза: `RACE_PERF=1 SMOKE_ROOT=public node output/monkey-race/check.cjs`.
