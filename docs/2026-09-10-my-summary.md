# Моя сводка

Компактный вход над «Раздачей дня» на главной, отдельный экран `my-summary`.

Источники: статус Daily Poker (с серверным временем и условиями участия), сохранённый профиль Poker21 без принудительного обновления, существующая история турнирных достижений, расписание с московским временем, активные розыгрыши, состояние прочтения новостей друзей. Призовые не называются прибылью; количество результатов — только оплаченные места. Позиция «Героя месяца» рассчитана по званиям героя дня и сумме призовых этих дней, как в новостях клуба.

Можно скрывать/показывать три показателя достижений; выбор хранится отдельно для каждого accountId. Ошибки отображаются по отдельным блокам. Смена авторизации инвалидирует незавершённые запросы и очищает личные данные. Кэш сводки 30 секунд, отсчёт работает только на открытом экране. Участие в розыгрыше показывается при совпадении canonical accountId; иначе отображается количество активных розыгрышей без утверждения об отсутствии участия.

Проверки: полный build; синтаксис 427 JS / 80 CSS; 14 тестов friend-news; Playwright `output/my-summary-check/browser.cjs` (мобильная ширина, таймер, бесплатный вход, личный розыгрыш, выбор достижений, новости, offline, выход); `integration.cjs` (полная страница, настоящее расписание, динамические переходы).

API в браузерных проверках заменены фикстурами; реальный аккаунт не проверялся. Изменения не опубликованы.


## Стартовые руки — 12 сентября 2026

В «Моей сводке» добавлена карточка «Стартовые руки». Открывает встроенный полноэкранный просмотр с возвратом в сводку. Общедоступные файлы `starting-hands/` содержат только интерфейс, без персональных данных. Матрица загружается через POST /api/starting-hands; действия — по раскрытию раздачи. При смене авторизации просмотр закрывается, поздние ответы не применяются.

Сервер использует общий авторизационный контекст приложения, определяет привязанный Poker21 ID на сервере и читает только его раздел Redis. Переданный клиентом playerId не используется. Ответы private/no-store. Пользователю без привязки предлагается привязать Poker21; при отсутствии импорта отображается пустая выборка.

Сохранены Кеш / MTT / SNG, результат по умолчанию в bb, пронумерованные раздачи, включённые фильтры «Плюсовые» / «Минусовые» под результатом, действия по улицам, цветные масти и сопоставленные ники.

Импорт: scripts/upload-starting-hands.cjs читает подготовленные локальные проекции и реплеи, проверяет владельца и наличие историй, сохраняет сжатые записи в версионированном Redis hash и переключает активную версию только после проверки количества. Исходные выгрузки не входят в git или публичную сборку. После разрешения пользователя получены только два параметра Redis; секреты не записывались на диск. В production загружено 2664 раздачи (1467 кеш, 1197 MTT), активная версия 049fc474c703176d. Обратным чтением проверены владелец всех строк, 2665 полей хранилища (список + реплеи) и раскрываемая история.

Проверки: 15 тестов (расчёты, сводка, изоляция API), полный build, мобильный браузерный сценарий сводка → матрица → фильтр → история → очистка при смене авторизации с тестовыми ответами API. Публичный экран отвечает HTTP 200; API без авторизации требует вход. Получение данных через реальный авторизованный аккаунт в браузере отдельно не проверялось.

Следующий этап: выбор периода и кабинет управляющего с серверной проверкой прав. Не реализованы.
