# Моя сводка

Компактный вход над «Раздачей дня» на главной, отдельный экран `my-summary`.

Источники: статус Daily Poker (с серверным временем и условиями участия), сохранённый профиль Poker21 без принудительного обновления, существующая история турнирных достижений, расписание с московским временем, активные розыгрыши, состояние прочтения новостей друзей. Призовые не называются прибылью; количество результатов — только оплаченные места. Позиция «Героя месяца» рассчитана по званиям героя дня и сумме призовых этих дней, как в новостях клуба.

Можно скрывать/показывать три показателя достижений; выбор хранится отдельно для каждого accountId. Ошибки отображаются по отдельным блокам. Смена авторизации инвалидирует незавершённые запросы и очищает личные данные. Кэш сводки 30 секунд, отсчёт работает только на открытом экране. Участие в розыгрыше показывается при совпадении canonical accountId; иначе отображается количество активных розыгрышей без утверждения об отсутствии участия.

Проверки: полный build; синтаксис 427 JS / 80 CSS; 14 тестов friend-news; Playwright `output/my-summary-check/browser.cjs` (мобильная ширина, таймер, бесплатный вход, личный розыгрыш, выбор достижений, новости, offline, выход); `integration.cjs` (полная страница, настоящее расписание, динамические переходы).

API в браузерных проверках заменены фикстурами; реальный аккаунт не проверялся. Изменения не опубликованы.


## Стартовые руки — 12 сентября 2026

В локальной «Моей сводке» добавлена карточка «Стартовые руки» с переходом к прототипу на http://127.0.0.1:4318/. Карточка появляется после ответа профиля только для привязанного Poker21 ID 208238 (ПокерМанки); ник не используется для определения владельца. На публичном домене карточка скрыта: персональные выгрузки не включаются в публичную сборку.

Прототип: отдельные Кеш / MTT / SNG, матрица стартовых рук, результат по умолчанию в bb, список пронумерованных раздач, включённые по умолчанию фильтры «Плюсовые» / «Минусовые» под результатом, раскрытие действий по улицам, цветные масти и сопоставленные ники.

Следующий этап интеграции: серверная выдача истории с проверкой владельца, встроенный экран вместо локального перехода, выбор периода (неделя / месяц / всё время). Затем доступ остальным игрокам; для управляющего — выбор игрока с серверной проверкой прав. Эти этапы пока не реализованы.
