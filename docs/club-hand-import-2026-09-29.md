# Дозагрузка раздач за 28 сентября 2026

Общий экспорт Poker21 без фильтров по клубу, лиге и игроку дал **22 836 уникальных раздач** за 28 сентября по Новосибирску (00:00:00–23:59:59). Экспорт был разделён на четыре шестичасовых интервала из-за ограничения сайта на объём однодневной выгрузки. Записи относятся к семи `GroupId` столов; это область ответа аккаунта `KampashkaPoker21`, а не подтверждение охвата всей платформы или членства игроков в этих клубах.

Компактные строки CSV декодированы в обычный формат Poker21. **7 805 раздач**, присутствующих и в прежнем JSON-экспорте, сверены по идентификаторам, датам, игрокам, результатам, картам, действиям, итоговым взносам и комиссиям: расхождений нет. Исходный CSV, четыре части и декодированный JSONL сохранены локально в `output/poker21-bulk-export-2026-09-29`.

Текущие привязки в базе повторно сверены с сохранённым списком: те же **452 игрока** клуба 758417. Для них подготовлены 29 669 личных записей из 13 499 поддерживаемых раздач. Загрузчик пропустил 8 407 уже присутствовавших личных записей и добавил **21 262 новые записи для 124 игроков** без конфликтов. Все версии проверены при записи и переключены атомарно.

EV для 21 262 новых записей: рассчитан для **919**, неприменим для **19 985**, неопределён для **358**. Ранее сохранённые EV не менялись. После записи EV повторное чтение Redis подтвердило активные истории 136 затронутых игроков и все **388 017** записей в них.

Импортёр исключил **432 раздачи** с неподдерживаемыми игровыми кодами (`214/2008`, `0/2018`, `0/2019`) и **одну** с неоднозначным большим блайндом. Все эти строки остаются в исходном CSV и JSONL; их нельзя безопасно добавить в статистику NLH/PLO как другой вид игры. Список игр сайта отдельно с общим экспортом не сверялся, поэтому полнота за пределами ответа этого аккаунта не установлена.

Локальные личные проекции, планы, журналы и результаты EV находятся в `output/club-hand-import-2026-09-29`, `output/club-hand-ev-2026-09-29` и `output/club-hand-ev-apply-2026-09-29`; они содержат приватные данные и не предназначены для публичной сборки.
