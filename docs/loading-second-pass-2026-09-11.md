# Второй проход оптимизации загрузки — 11 сентября 2026

Главный оставшийся источник стартового трафика оказался в изображениях. Пять крупных декоративных картинок занимали 923 982 байта, хотя показываются значительно меньше исходного размера. Для них созданы WebP-варианты подходящего размера: суммарно 451 492 байта, экономия 472 490 байт. Оригиналы сохранены. Ссылки на дублирующие декоративные слои CSS также обновлены, чтобы браузер не скачивал одновременно старую и новую версии. Картинка зала славы ниже первого экрана теперь загружается лениво с низким приоритетом; основное изображение первого экрана сохранило высокий приоритет.

Из начальной загрузки дополнительно вынесены стили устава, приветствия, газеты, VPN, реферального окна, инструкции установки и редакторского планера. Планер проверяет доступ до загрузки своего CSS. Окна ждут готовности оформления; закрытие отменяет отложенное открытие, ошибки позволяют повторить попытку. Критическое скрытие закрытых окон осталось в стартовом CSS.

Из styles.css и home-overrides убрано 119 избыточных деклараций: точные повторы и перекрытые поздними правилами простые числовые размеры с тем же селектором, условием media/supports и приоритетом. Не выполнялось массовое удаление правил по названиям «legacy» или предположению, что они не используются. При сравнении окон восстановлен прежний слой кнопок закрытия: они продолжают использовать общее правило touch-targets.

## Контрольный замер

Холодный браузерный контекст, production-сборка, viewport 390×844, DPR 2, CPU ×4, 200 000 байт/с и задержка 100 мс. Локальный сервер отдаёт текстовые ресурсы с gzip, service worker выключен; внешние запросы блокируются, API заменены тестовыми ответами. Это одна сопоставимая пара прогонов, а не оценка реального API или гарантия скорости у всех пользователей.

## Проверки

- Сборка, синтаксис изменённых JS и всех 85 CSS-файлов — успешно.
- 4 unit-теста ожидания CSS: готовый файл, закрытие до загрузки, повторные клики, ошибка и повтор — успешно.
- 7 окон открываются и закрываются на 390/1280 px. Вычисленные стили видимых элементов совпали с исходными после нормализации адреса локального тестового сервера. Гость не открывает планер и не запрашивает его CSS; тестовый редактор загружает его один раз.
- Визуальный smoke основных экранов с возвратом на главную — успешно. Изображения главной и планер дополнительно просмотрены на снимках.
- Обновление PWA v62 → v63 — успешно, черновик сохраняется до явного обновления.

Параллельные тяжёлые браузерные прогоны были остановлены из-за нагрузки на среду; финальный визуальный прогон завершён отдельно. Для исходных снимков использованы сохранённые исходники и оригиналы картинок, поскольку новая сборка уже не содержит неиспользуемые старые изображения.

Повторить замер: `npm run measure:startup`. Сравнивать следует одинаковые параметры и свежие контексты; `MOBILE_OUTPUT_DIR` задаёт каталог отчёта. Перегенерировать изображения: `npm run assets:home-art`, затем `npm run build:static`. Проверить окна: `npm run smoke:home-modals`. Данные текущего сравнения находятся локально в `output/loading-second-pass-2026-09-11/`.

Оставшиеся ограничения: рабочие API, внешние шрифты и реальные iPhone/Android в этот замер не входят. Скрипты и остальные картинки по-прежнему составляют часть загрузки; этот проход завершает перечисленные изменения, но не означает отсутствия дальнейших возможностей оптимизации.
