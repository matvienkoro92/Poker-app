# Отдельная версия для магазинов

Согласованная модель: игровые фишки нельзя купить или обменять на деньги либо
материальные призы. Интерфейс одинаков для пользователей и модераторов.

`npm run store:prepare` собирает актуальные исходники в
`output/store-release/native/www`, не изменяя сайт, `public/` или основной
Android-проект. Используется существующий сборщик статических файлов; отдельная
HTML-обработка удаляет кассу, административные экраны, платные VPN/видеокурс и
исторические финансовые истории. Цифровые обозначения используют знак фишки `◉`.
Оригинальные API-поля, секреты и обработчики не изменяются. Поздно загруженные
подписи конвертируются только в этой версии.

Для подготовки HTML нужен локальный Chromium из Playwright. `npm run
store:verify` проверяет гостевой интерфейс на экране 390×844, поздно добавленные
подписи, запрещённый переход в кассу и сохраняет скриншоты. Внешние запросы при
этой проверке отключены; это не проверка входа или серверных операций.

В `output/store-release/native` находится отдельный Android-проект и Capacitor
конфигурация без `server.url`: интерфейс находится внутри приложения.
После подготовки нужно выполнить из этой папки `npm run android:sync`.
Сборка Android требует JDK 21 и Android SDK 36. Перед выпуском требуется настроить
подпись собственным ключом: исходный Android-проект пока не содержит release
signing configuration. Команды `npm run android:apk` и `npm run android:aab`
не следует считать подтверждением подписи без проверки полученного артефакта.

## Ещё не готово для подачи

- Проверка картинок и архивных скриншотов: текстовая конвертация не меняет пиксели.
- Проверка авторизации, API и внешних ссылок на устройстве.
- Политика конфиденциальности, контакт владельца, сведения о данных и удаление
  аккаунта: пока не подтверждены.
- Подпись APK/AAB и аккаунты RuStore/Google Play.
- Для iOS необходимы отдельная установка `@capacitor/ios`, Xcode, iOS-проект,
  подпись и Apple Developer; iOS-проект ещё не создан.

`build-report.json` содержит перечень преобразований и оставшихся проверок.
Сборка не публикуется автоматически и не гарантирует прохождение модерации.
