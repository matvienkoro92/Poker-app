# Подготовленные сцены

Статус: подготовлены отдельно; действующие дневные сцены не переключены.
Открыть preview.html для просмотра всех семи дней. manifest.json содержит
победителей, призовые за первые места, файлы и настройки бонуса.
FrankL = Morf, ШАХиМАТ = Gucci — подтверждено пользователем.

Шесть WebP обслуживают семь дней: ПокерМанки используется в понедельник и субботу.
Изображения 1122×1402; не выдавать их за нативный Retina-рендер.
Промпты встроенного image_gen: prompts.json.

При подключении:
- Выбирать сцену по турниру/бай-ину, используя weekday только для текущего расписания.
- Не переносить субботнее отключение бонуса на понедельник: оба используют ПокерМанки.
- Отключить старые заплатки фона, швы, затемнители, маски голов прежних героев.
- Название, время, фонд, кубок и приглашение — HTML поверх чистого билета.
- Фишки: центры X примерно 12.3%, 31%, 50%, 87.4%; Y около 73%.
- LAST LONGER: центр около 49%, 47%; зоны клика сверить в мобильном превью.
- Перчатка для остальных дней — отдельный существующий HTML/asset в свободном
  слоте X=68.5%; в субботу отсутствует. В фон её не запекать.
- Подготовить индивидуальные маски головы для перекрытия суммы фонда и проверить
  живые надписи: у новых персонажей силуэты отличаются от ПокерМанки.

Проверено: правильные образы, чистые билеты без внутренних красных рамок,
четыре стопки фишек, один стол, отсутствие перчатки в фоне; размеры и декодирование
WebP. Полная интеграционная проверка с живым UI нужна при подключении.
