# KotikMult AI

Standalone static education landing page for matvienko-roman.ru. No dependencies or build step. Source is isolated from the poker miniapp.

Preview: `python3 -m http.server 4178 --directory sites/kotikmult-ai` from the parent workspace.

Vercel: create a separate project, select this directory as Root Directory, Framework Preset Other, no Build Command, Output Directory `.`. Add matvienko-roman.ru and www.matvienko-roman.ru in project Domains, then use the exact DNS records Vercel supplies in REG.RU. Do not reuse the poker project's Vercel project ID.

The page links to https://t.me/KotikMult_AI_bot and https://www.instagram.com/kotikvpn/. Curriculum steps are illustrative workflow, not an asserted confirmed syllabus.
